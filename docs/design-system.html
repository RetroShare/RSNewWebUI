There is no component layer. components/ holds 1,250 lines; pages/ holds 12,000. Mail, boards, channels and forums each built their own card, button, avatar and empty state. The only shared JS modules are Sidebar, SidebarQuickView, popupMessage, Dialog and the comment tree.

The naming has no convention. Overlays are spelled four ways at once: -modal, -dialog, -popup, and camelCase composePopup / shareManagerPopup.

The brand went missing. The web UI's blues — #019dff, #0284c7, #3ba4d7, #007bff, #0788cb — are four unrelated blues plus Tailwind's sky ramp, none of which is RetroShare's. Only $primary-retro-color: #118fcc was the real thing, used fourteen times against Tailwind slate's nine hundred. The sidebar's own connection dot is hardcoded #2ecc71 / #e74c3c inline in main.js — a third palette again.

Four ideas of "small". _responsive.scss defines $bp-mobile: 700px, $bp-narrow: 899px and $bp-short: 500px, while the page stylesheets independently stack at 768px and 899px. Same product, four thresholds.

Reach: the gradient as an information scale

The logo is a gradient from pale sky to brand blue. In a friend-to-friend network the most important fact about anything on screen is how far it travelled to reach you — so that gradient becomes the scale. Saturation falls with distance.

Direct One hop Two or more hops Offline · last seen 3d
Four steps of one hue, taken from the logo gradient. Not a traffic light — distance is a continuum, not a severity.

This is why green and red stay reserved. If #32cd32 means "connected" it cannot also mean "uploading", and the two facts are independent — a peer three hops away can be your fastest transfer. Hue carries distance; green and red carry transfer direction only.

Weights: 400 body, 600 emphasis, 700 headings. Today there are eleven spellings, including the invalid font-weight: medium in _navbar.scss.
The floor is 13px, and 11px is not a general-purpose size Anything carrying a sentence, a name or a value you have to read sits at 13px or above. --t-micro exists for three things only — unread counts, tags and status pills — where the shape and colour do the work and the number is a glance, not a read. The current UI runs body text at 0.7rem (11.2px) and metadata at 0.75rem in dense screens, which is why it feels cramped rather than dense.

Icons

118 distinct Font Awesome glyphs are in use today, across eight fa-user-* variants, eight fa-file-* variants and four ways of saying "comment". Consolidated, the real vocabulary is about eighty concepts.

Recommendation: Phosphor, regular weight as default, duotone for state MIT licensed, 1,248 icons in six weights, drawn on a 16px grid — which matters at the 19px we render nav icons at. Phosphor is the one free set that ships duotone as a native weight, and that is not a decorative preference: the duotone layer is a separate path with its own fill, so it can carry the reach colour while the stroke stays ink. One icon then encodes both what a thing is and how far away it is, with no separate dot.

Against the alternatives: Lucide and Tabler are excellent and slightly larger, but both are stroke-only, so state would need a second element; Lucide is also drawn for 24px and thins out under 20. Remix has line/fill pairs but no true duotone and a heavier, rounder voice that fights the Qt lineage. Font Awesome's own duotone is Pro-only, so it is not on the table.

The phone row is the one already built. PR #121's _responsive.scss carries a genuine phone layer including the landscape-short compound (max-width: 899px) and (max-height: 500px), a touch mixin for (hover: none), and $touch-target: 2.75rem. None of that is lost in a repaint — it is layout and behaviour, not colour.

Touch targets are a floor, not a suggestion Under the touch mixin every control goes to 44px minimum, including sidebar items, tabs, row hit areas and the sheet's close. Buttons stay 30px on pointer devices so density survives where density is wanted.

Presence bridge

One meter per friend node: height is live throughput, colour is how that peer reaches you on the reach scale. Offline nodes keep their slot, so the shape of your mesh stays constant and you notice when it changes.

Migration

The first two steps are done and sitting uncommitted in the working tree.

  1. Token layer — done. 1,197 hex literals and 34 color.adjust() calls moved to CSS custom properties in abstracts/_tokens.scss. Verified pixel-identical against the previous build.
  2. Remove the bevel and the route fades — done. Also deleted the 20-line override block that existed only to undo the bevel.
  3. Repaint to the brand palette — edit _tokens.scss alone, adding the type scale beside the colours.
  4. Swap the icon set — build the Phosphor sprite, map the 118 glyphs onto ~80 symbols, drop Font Awesome and its webfonts.
  5. Build the component layer — the elements and components above, in components/. Roughly 500 lines of new CSS.
  6. Rework the sidebar — persistence, the always-visible toggle, tooltips, and the width change.
  7. Convert one screen end to end — Forums. It exercises the row, the reading column, tabs, the toolbar, the sheet and the empty state.
  8. Delete as the rest follow — each converted page should remove more lines than it adds. If it does not, the component set is wrong.
