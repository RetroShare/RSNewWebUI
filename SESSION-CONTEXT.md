## Repo layout notes

- Source is `webui-src/app`, build output is `webui/` (gitignored except
  `webui-src/styles.css`, which is tracked and must be rebuilt before commit).
- Mithril with a custom AMD-ish loader (`webui-src/make-src/template.js`).
- Sass modules. `webui-src/app/scss/` → `abstracts` (tokens, mixins), `base`,
  `components`, `layouts`, `pages`, `responsive` (must stay last).
- Icons: a Phosphor sprite generated by `webui-src/make-src/icons.js`. The `MAP`
  there is the list of legal `icon('name')` values — check it before using a
  name. Icons render as `<svg class="icon">`, so any old `button i` selector
  matches nothing.

  `'No forums to show'` placeholder, and `getForums` had no `Other` key (tab is
  named `Other`, data was under `All`).

## Gotchas found the hard way — don't rediscover these

**`display: flex` on a `<td>` breaks the table.** The cell stops participating
in the table's column layout; the browser wraps it in an anonymous cell, so the
header row and the body rows no longer share columns. Put the flex box in a
`<div>` *inside* the cell. This bit twice — `.group-row__name` and
`.forum-thread-row__cell`.

**Unread is a bit, not a value.** `rsgxsflags.h`:
`GXS_MSG_STATUS_GUI_UNREAD = 0x02`. The old code did
`mMsgStatus === 0x03`, which was true for almost no post — the Unread column was
permanently empty. Use `(status & 0x02) !== 0`.

**`<summary>` doesn't get `box-sizing: border-box`; `<button>` does.** A shared
`min-height` comes out 8px taller on a summary-based button. Set it explicitly.

**`[hidden]` loses to a class.** `.channel-post__placeholder { display: flex }`
outranks `[hidden]` (equal specificity, later in source), so a card rendered the
image *and* its fallback. Render one or the other instead.

**The base table stylesheet centres `td`.** Any new table needs an explicit
`text-align: left` or headers and values won't line up.

**`&` expands to the whole parent selector in Sass.** `> &__group` inside
`.page-head` becomes a leading `>` with nothing before it — invalid, silently
dead, and a Dart Sass deprecation warning at build time. Watch the build output.

**`userList.username()` returns the raw id when it can't resolve one**, and GXS
writes an all-zero id for an unsigned post. Fixed centrally in `rswebui`.

**`updatedisplayforums` rebuilds `Data.Threads` from scratch on every refresh.**
Anything cached on the struct (like a post body) must be carried across or the
open post flashes back to "Loading content...". There's a 30s background
refresh, so this fires constantly.

**Mithril**: a string `style` sets `cssText`, which is how CSS custom properties
get set per element (`style: \`--depth:${n}\``). An object style can't set
`--x`. Depth-as-a-variable also lets a media query override the step, which an
inline padding could not.

`text-overflow: ellipsis` elements, ignore absolutely-positioned popovers, and
